# 01. 공연정보

- **담당**: 조소영
- **출처**: (채우기) 예: 한국체육산업개발 영문 공연 정보
- **갱신**: (채우기)
- **샘플 여부**: (채우기) 진짜 데이터 / 샘플(_SAMPLE)

| 폴더 | 들어가는 것 |
|---|---|
| `raw/` | 전처리 전, 받은 그대로 |
| `processed/` | 전처리 후, 화면이나 기획서에 쓰는 표 |

> 아직 비어 있습니다. 파일을 올리면 위 네 줄의 (채우기)를 고치고, 아래처럼 파일 목록을 적어 주세요.

| 파일 | 내용 |
|---|---|
| (예) `raw/01_공연정보_20261125.csv` | 공공데이터포털에서 받은 원본 |
| (예) `processed/01_공연정보_20261125.csv` | 정리한 결과 |
