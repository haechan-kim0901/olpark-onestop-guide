|---|---|

|---|---|
| `processed/01_shows_20261126_SAMPLE.csv` | 데모용 가짜 공연 12건 (2025년 8월, 6건은 종료시각 빈 칸) |

## 진짜 공연 CSV 를 올리면 화면이 바뀝니다

1. 아래 열 이름 그대로 CSV 를 만들기 (UTF-8 BOM, 엑셀에서 "CSV UTF-8" 로 저장)
2. `processed/` 에 `01_shows_날짜.csv` 이름으로 올리기 (가짜면 끝에 `_SAMPLE`)
3. main 에 합쳐지면 GitHub Actions 가 1~2분 안에 `docs/data/shows.json` 을 새로 만들고, 데모 첫 화면 목록이 바뀜
   (진짜 파일이 있으면 `_SAMPLE` 파일보다 먼저 씀. 여러 개면 이름순 마지막 파일)

| 열 | 꼭 필요? | 예 |
|---|---|---|
| 공연명 | 필수 | 아티스트 A 월드투어 서울 |
| 공연장 | 필수 | KSPO DOME / 올림픽홀 / 핸드볼경기장 / 88잔디마당 (이 4개 이름만) |
| 공연일 | 필수 | 2025-08-09 |
| 시작시각 | 필수 | 18:00 |
| 공연명_영문 | 선택 | 비우면 한글 이름 그대로 |
| 종료시각 | 선택 | 비워도 됨. 화면에 '시작 + 2시간 30분 (예상)' 으로 표시 |
| 장르, 장르_영문 | 선택 | 콘서트 / Concert |
| 공연ID | 선택 | 비우면 자동. 공지(NOTICES)와 연결할 때만 필요 |

> 화면 타임라인은 **도착 권장(시작 3시간 전) → 공연 시작 → 퇴장** 3단계입니다. 3시간, 2시간 30분은 `docs/index.html` 의 `ARRIVE_BEFORE`, `END_AFTER` 에서 바꿀 수 있습니다.

> 공연장 이름이 다르거나 필수 칸이 빈 줄은 건너뛰고, Actions 기록에 몇 번째 줄인지 적어 줍니다.
