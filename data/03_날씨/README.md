# 03. 날씨

- **담당**: 김해찬
- **출처**: 기상청 단기예보 조회서비스 (초단기실황, 초단기예보), 올림픽공원 격자(62, 126)
- **갱신**: 자동, GitHub Actions 15분마다 (`scripts/update_weather.py`). 기상청 자료는 1시간마다 바뀜
- **샘플 여부**: 진짜 데이터

| 폴더 | 들어가는 것 |
|---|---|
| `raw/` | 전처리 전, 받은 그대로 |
| `processed/` | 전처리 후, 화면이나 기획서에 쓰는 표 |

| 파일 | 내용 |
|---|---|
| `raw/ultra_srt_ncst.csv` | 지금 관측값 (기온, 강수, 습도, 바람). 한 줄 = 항목 하나, `category_ko` 열에 항목 뜻 |
| `raw/ultra_srt_fcst.csv` | 앞으로 6시간 예보 |
| `processed/weather_now.csv` | 지금 기온, 체감온도, 습도, 바람, 강수 (1줄) |
| `processed/weather_hours.csv` | 앞으로 6시간 기온, 체감온도, 하늘, 강수 |

- 같은 이름의 `.json` 은 API 응답 원본(증빙용)입니다. 인증키는 어떤 파일에도 없습니다.
- 하는 일: 세로 표를 시각별 가로 표로 바꾸기, 체감온도 계산, 하늘 코드(1, 3, 4)를 글자(맑음, 구름많음, 흐림)로. 자세히는 `notebooks/03_weather_api.ipynb`
- 웹 화면은 `docs/data/weather.json` 을 읽습니다 (여기 CSV 와 내용이 같음).
- 자동 갱신 파일이라 **이름을 바꾸거나 옮기지 마세요.** 바꾸면 자동 갱신이 옛 위치에 다시 만듭니다.
