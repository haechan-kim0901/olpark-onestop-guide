# 05. 주차장

- **담당**: 한성우 (입출차 연계), 차승우 (주차 혼잡도, 실시간 주차)
- **출처**: (채우기) 예: 한국체육산업개발 차량 입출차, 공연 연계 데이터
- **갱신**: 노트북 01 실행 후 직접 올림
- **샘플 여부**: **지금은 합성(가짜) 샘플**, 파일 이름 끝에 `_SAMPLE`

| 폴더 | 들어가는 것 |
|---|---|
| `raw/` | 전처리 전, 받은 그대로 |
| `processed/` | 전처리 후, 화면이나 기획서에 쓰는 표 |

| 파일 | 내용 |
|---|---|
| `raw/schedule_SAMPLE.csv` | 합성 공연 일정 (연습용) |
| `raw/parking_SAMPLE_first1000.csv` | 합성 입차 기록 앞 1,000줄 (전체 8만여 줄은 노트북이 만들어 씀) |
| `processed/parking_entry_hourly_SAMPLE.csv` | 시간대별 평균 입차 대수 (공연일, 비공연일, 몇 배) |
| `processed/parking_daily_SAMPLE.csv` | 날짜별 입차 합계, 공연 여부, 공연장 |
| `processed/parking_cleaning_log_SAMPLE.csv` | 정리 단계별 행 수 (기획서 전처리 설명에 활용) |

- **진짜 주차 원본 CSV 는 용량이 커서 GitHub 에 올리지 않습니다.** (`.gitignore` 가 이 폴더 `raw/` 의 CSV 를 막고, `_SAMPLE` 파일만 통과시킴) Colab 에 직접 올려 쓰세요.
