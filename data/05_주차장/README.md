# 05. 주차장

- **담당**: 한성우 (입출차 연계), 차승우 (주차 혼잡도, 실시간 주차)
- **출처**: 한국체육산업개발 차량 입출차 이력(API_CPM_008), 공연 연계 데이터(API_CPM_009, 시간별), 공연정보 API
- **갱신**: 노트북 01 실행 후 직접 올림
- **샘플 여부**: `_SAMPLE` 이 붙은 파일은 합성(가짜) 샘플. `05_주차장기준표` 등 아래 '예측 모델' 파일 5개는 실제 데이터로 만든 결과

| 폴더 | 들어가는 것 |
|---|---|
| `raw/` | 전처리 전, 받은 그대로 |
| `processed/` | 전처리 후, 화면이나 기획서에 쓰는 표 |

| 파일 | 내용 |
|---|---|
| `raw/schedule_SAMPLE.csv` | 합성 공연 일정 (연습용) |
| `raw/parking_SAMPLE_first1000.csv` | 합성 입차 기록 앞 1,000줄 (전체 8만여 줄은 노트북이 만들어 씀) |
| `processed/parking_entry_hourly_SAMPLE.csv` | 시간대별 평균 입차 대수 (공연일, 비공연일, 몇 배) |
| `processed/parking_daily_SAMPLE.csv` | 날짜별 입차 합계, 공연 여부, 공연장 |
| `processed/parking_cleaning_log_SAMPLE.csv` | 정리 단계별 행 수 (기획서 전처리 설명에 활용) |

- **진짜 주차 원본 CSV 는 용량이 커서 GitHub 에 올리지 않습니다.** (`.gitignore` 가 이 폴더 `raw/` 의 CSV 를 막고, `_SAMPLE` 파일만 통과시킴) Colab 에 직접 올려 쓰세요.
- 진짜 데이터로 노트북 01 을 돌리면 `_SAMPLE` 없는 결과 파일이 나옵니다. 그 파일을 `processed/` 에 올리고 `_SAMPLE` 파일은 지워 주세요.
- 하는 일: 결측, 중복, 날짜 오류 제거, 공연 일정과 날짜로 합치기, 시간대별 평균. 자세히는 `notebooks/01_preprocess_parking.ipynb`

### 예측 모델 파일 (2026-11-27, 실제 데이터)

주차 혼잡 단기 예측(`scripts/parking_predict.py`)이 읽는 파일입니다. 이름은 `번호_데이터명_날짜` 규칙을 따르고, 코드는 같은 데이터명 중 **가장 최근 날짜** 파일을 씁니다. 자세한 설명은 [`예측모델_설명.md`](예측모델_설명.md).

| 파일 (`processed/`) | 내용 |
|---|---|
| `05_주차장기준표_20261127.csv` | 요일유형(평일/휴일/명절) × 시각별 평소 사용 대수(중앙값, 하위 10%, 상위 10%). 3문권역(남2+동2+북2) 기준 |
| `05_주차장예측계수_20261127.json` | 현재 값이 몇 시간 뒤까지 남는 비율, 공연 보정 계수, 절편 |
| `05_주차장예측설정_20261127.json` | 혼잡 기준(1300 이상 혼잡, 1900 이상 만차), 문별 평균 비중, 관측 최대 |
| `05_주차장문별비중_20261127.csv` | 요일 × 시각별 동2문, 남2문, 북2문 비중(문별 추정값 계산용) |
| `05_주차장공연일정_20261127.csv` | 2025~2026 공연 일정(공연장, 시작 시각), 일부는 관람객 수 포함 |

- 실시간 값을 쌓는 `parking_live_log.csv` 는 `raw/` 에 자동으로 생기고, `.gitignore` 때문에 저장소에는 올라가지 않습니다.
- 원본 입출차 CSV(약 240만 행)와 전처리 코드는 올리지 않습니다.
