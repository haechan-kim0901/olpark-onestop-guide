# data 폴더 안내

데이터 **종류별로 폴더 하나**씩 있습니다. 모든 폴더 안 모양은 같습니다.

```
data/
├─ 01_공연정보/        담당 조소영
├─ 02_공중화장실/      담당 조소영
├─ 03_날씨/            담당 김해찬 (15분마다 자동 갱신)
├─ 04_물품보관함/      담당 김해찬 (15분마다 자동 갱신)
├─ 05_주차장/          담당 한성우, 차승우 (지금은 샘플)
├─ 06_공원볼거리/      담당 한성우
└─ 07_주변관광정보/    담당 정한솔

각 폴더 안
├─ raw/          ← 전처리 전: 받은 그대로 (고치지 않기)
├─ processed/    ← 전처리 후: 정리한 결과
└─ README.md     ← 담당, 출처, 갱신 날짜, 샘플 여부 (3~4줄)
```

## 약속

1. **CSV 는 UTF-8 BOM** 으로 저장 (엑셀에서 한글 안 깨짐). 날짜는 `YYYY-MM-DD HH:MM` (한국 시간)
2. 새 파일 이름은 `번호_데이터명_날짜.csv` (예: `02_공중화장실_20261125.csv`)
3. **가짜, 연습용 데이터는 이름 끝에 `_SAMPLE`** (예: `02_공중화장실_20261125_SAMPLE.csv`)
4. 파일을 올리면 그 폴더 `README.md` 의 (채우기) 부분을 고치기
5. 인증키(API 키)는 어떤 파일에도 넣지 않기
6. 03_날씨, 04_물품보관함 파일은 자동으로 만들어지니 이름을 바꾸거나 옮기지 않기

> 웹 데모 화면은 이 폴더가 아니라 `docs/data/*.json` 을 읽습니다. 여기 CSV 는 팀 확인용, 기획서 근거용입니다.
> `.gitkeep` 은 빈 폴더를 GitHub 에 남기려고 넣은 빈 파일입니다. 파일을 올린 뒤 지워도 됩니다.
